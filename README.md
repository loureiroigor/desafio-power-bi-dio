# Primeiro Dashboard no Power BI - Desafio DIO

Este repositório contém a minha entrega para o primeiro desafio prático de Power BI da DIO. O objetivo do projeto foi importar uma base de dados financeira, tratar as informações e criar um relatório interativo, replicando duas páginas ensinadas no curso e criando uma terceira página de forma autônoma.

## O que foi desenvolvido

O relatório foi construído utilizando a base de dados `Financial Sample` e está estruturado em três páginas:

* **Páginas 1 e 2:** Relatórios guiados, construídos para treinar a importação de dados, formatação de visuais básicos e aplicação de filtros (réplica das aulas da instrutora Juliana Zanelatto).
* **Página 3 (Desafio Prático):** Página desenvolvida do zero para fixar o conhecimento, contendo:
  * Gráfico de pizza apresentando o **Lucro por Segmento**.
  * Visual de mapa exibindo **Vendas e Unidades por País** (com as unidades configuradas nas dicas de ferramentas/tooltips).
  * Visual de mapa detalhando o **Lucro por País**.

Durante a construção da última página, também realizei ajustes na disposição do layout e renomeei os títulos automáticos dos gráficos para descrições mais diretas e fáceis de ler.

* Power BI Desktop
* Excel (Fonte de Dados)

## Como visualizar o projeto

Para abrir e interagir com o relatório, você precisa ter o [Power BI Desktop](https://powerbi.microsoft.com/desktop/) instalado no seu computador. Basta clonar este repositório ou baixar o arquivo `.pbix` diretamente e abri-lo no programa.
